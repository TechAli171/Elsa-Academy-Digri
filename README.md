# Elsa Academy Degree — Front-End Website

A responsive front-end concept for Elsa Academy Degree.

## Included sections
- Home / Hero
- About the Academy
- Student Management
- Online Testing
- Class Schedule
- Computer Courses
- Student Dashboard preview
- Contact / CTA
- Responsive mobile navigation
- Working sample online quiz interaction

## Run
1. Extract the ZIP.
2. Open `index.html` in any modern browser.
3. No installation or server is required for this front-end demo.
